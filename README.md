# Semantic HTML Cleaner

Semantic HTML Cleaner is a lightweight tool designed to clean and normalize HTML documents by removing unnecessary tags, fixing structural issues, and improving semantic correctness.

The project helps developers transform messy or poorly structured HTML into clean, readable, and semantic markup.

Semantic HTML improves accessibility, SEO, and code maintainability by ensuring HTML elements accurately represent their meaning and structure. :contentReference[oaicite:1]{index=1}

---

## Features

- Cleans malformed or messy HTML
- Converts non-semantic tags into semantic HTML elements
- Removes unnecessary inline styles
- Improves HTML readability
- Helps maintain consistent HTML structure
- Useful for preprocessing HTML before publishing or analysis

---

## Why Semantic HTML Matters

Using semantic HTML improves:

- **Accessibility** – Screen readers can interpret page structure better.
- **SEO** – Search engines understand page content more effectively.
- **Maintainability** – Code becomes easier to read and maintain.
- **Performance** – Cleaner markup reduces unnecessary complexity.

## Installation

Clone the repository:

```bash
git clone https://github.com/sufyanism/Semantic_HTML_Cleaner.git
cd Semantic_HTML_Cleaner
````

Create a virtual environment:

```bash
python -m venv venv
```

Activate environment:

Linux / macOS

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Usage

Run the cleaner:

```bash
python main.py input.html output.html
```

Example:

```bash
python main.py messy.html clean.html
```

The script will:
1. Parse the HTML file
2. Remove unnecessary elements
3. Normalize HTML structure
4. Output a cleaned semantic HTML document

---

## Example
### Input (Messy HTML)

```html
<div>
<div class="title">Hello World</div>
<div>This is a paragraph</div>
</div>
```

### Output (Semantic HTML)
```html
<article>
<h1>Hello World</h1>
<p>This is a paragraph</p>
</article>
```
